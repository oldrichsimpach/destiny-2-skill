# Changelog

## 0.4-beta.1 — 2026-11-02 — experimental beta

- Added 82 scoped evidence records, explicit conflicts, patch/unit/mode/component gates and persistent invalidation checks.
- Integrated read-only Boss Damage and reserve workbooks, 6,026 row locators and structured array formula handling; public packages omit full originals.
- Added exact-version manifest checks for sockets, classes, slots and equipping unique labels; optional audited aspect/fragment/artifact/mod policies preserve unknown server conditions.
- Added bounded action/event simulation: charge/recovery/reload/swap/travel/ticks, typed effect categories, hit/cast procs, ammo/refills, movement and range scenarios.
- Added sequential ability charge/energy accounting, chunk/class scalars, refunds, typed incoming attacks, independent DR groups, overshields and healing.
- Added seeded Monte Carlo for nonlinear procs and finite candidate/inventory/Pareto comparison; ensemble summaries retain explicit sample-trace labels.
- Added source fingerprints, official-patch mention review, affected-result reporting and persisted needs_review flags that block stale claim reuse.
- Added synthetic reference scenarios and 46 new tests; all 64 tests pass. Actual manifest reissues and source-row readers were also checked. Prior releases/data retain their original scope and dates.

Limits remain: no complete game simulation, complete current numerical/rule corpus, global loadout solver, automatic coefficient adoption or server equipability certification.

## 0.3-beta.1 — 2026-11-01 — experimental beta

- Aegis Endgame Analysis becomes the primary community source for covered endgame PvE topics, with Bungie, legal-roll and stacking checks retained.
- Audit of all 52 sheets, including 16 hidden sheets; per-tab author dates, source SHA, formula/comment counts, exclusions and documented schema differences.
- New read-only `aegis.py`: sheet inventory, name/detail search, exact rows with headers/formulas/comments, import and independent checks of standard archetype arithmetic against cached results.
- Dated name/row index works without the original. Local installation includes the downloaded XLSX; public release references the original and provides an import command because no full-workbook redistribution license was established.
- Guards for unrelated perk-column ordering, tier-list-local rankings, ignored pre-TFS armor/build tabs, hypothetical tuning, mixed artifact eras, uncertain values and normalized damage baselines.
- Preserves v0.2 mathematical tools and dated datasets without silently replacing their patch assumptions.

Still experimental: no complete sandbox simulator, exhaustive legal-roll solver, automatic source sync or independent validation of every source claim. Cached arithmetic checks do not validate in-game damage. v0.1 and v0.2 releases remain available.
